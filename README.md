# psf-droneracing-mujoco
a  quadrotor simulation in MuJoCo to test a Predictive Safety Filter (PSF) 

## Quickstart

Python version 3.10 or later required
```
git clone https://github.com/darrenbiskupphd/psf-droneracing-mujoco
pip install mujoco jax scipy matplotlib
cd psf-droneracing-mujoco
python main.py
```
